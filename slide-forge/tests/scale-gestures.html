slide-forge — scale/zoom gesture tests

Runs entirely in a browser — no Node/npm required. Verifies the editor's stage-zoom (Forge.setZoom/toggleFocus) and corner-drag resize math (startDrag's scale()) stay correct at multiple zoom levels, which tests/editor-ops.mjs (jsdom) cannot check — jsdom returns zero for every getBoundingClientRect(). See tests/README.md.

Open this file via python -m http.server from the repo root (file:// blocks the iframe's same-origin access to window.Forge) and load http://localhost:PORT/slide-forge/tests/scale-gestures.html.
