Families of models

Two ways to learn

Supervised

Learn from answers

  • Trained on labeled examples — input paired with the correct output
  • Goal: predict the label for inputs it has never seen
  • Spam filters, image tagging, price forecasting
VS
Unsupervised

Learn from structure

  • No labels — the model finds patterns in raw data on its own
  • Goal: reveal hidden groupings, similarity, or compression
  • Customer segments, anomaly detection, embeddings

Under the hood

Learning, in five lines

train.py — scikit-learn
from sklearn.linear_model import LogisticRegression

model = LogisticRegression()
model.fit(X_train, y_train)      # nudge weights to fit the data
preds = model.predict(X_test)    # generalize to unseen inputs
print(accuracy(y_test, preds))   # did it actually learn?

Every framework hides the same loop: fit on what you know, predict on what you don't, then measure the gap.
