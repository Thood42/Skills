# Claude Skills Workspace

Development workspace for custom Claude Skills.

## Structure

```
Skills/
├── Slides/          # HTML slide deck generator skill
│   ├── SKILL.md     # Skill definition
│   ├── scripts/     # Python build/lint/export tooling
│   ├── references/  # Theme, chart, and layout documentation
│   ├── vendor/      # Vendored third-party libraries
│   └── *.html       # Reference decks and galleries
└── slides-vendored-libs-plan.md
```
