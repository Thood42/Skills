# Feature plans

One folder per feature: `docs/plans/<feature-slug>/` with `00-status.md`, `01-product.md`,
`02-architecture.md`, `03-program-design.md`, `04-slices.md` (and `mockups/` for webview UI).
`00-status.md` records gate approvals, review verdicts and the slice checklist; a new session
resumes from it.
