A nine-item list — the stagger no longer runs out

    Today the sequence is written out by hand and stops at the sixth item, so items 7, 8 and 9 all land together with item 1. Handing each item its own position removes the ceiling — and the same number that spaces these items is the one the dial above changes.

    titleheadline of the slide
    kickerthe eyebrow above it
    leadsubtitle or opening line
    listany set of siblings — bullets, stat cards, agenda rows, columns, tiles
    figurepicture, chart, table, diagram, code panel
    numbera figure that counts up to its value
    chromerails, marks, pagers — never animated
