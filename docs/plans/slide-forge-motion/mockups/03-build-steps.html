Stepping through a list is one capability; how each point arrives is a separate choice, with a default you set once for the deck and can override on any single slide. Pick a style and step through it. The stepping behaves identically in all five — only the arrival changes.

What this settles. Step-through is not one animation — it is a stepping rule plus a reveal style, and the two are chosen separately:
  • Appear / Wipe / Typewriter / Word by word hide the upcoming points until you call them.
  • Spotlight hides nothing — the full list is on the slide and the focus moves. Best when the room needs the shape of the list, and the only style that never withholds text from someone reading ahead.
  • The choice cascades: deck default → this slide → one specific element, the same shape as the motion dial, so there is one mental model rather than two.
  • With motion off — or for anyone whose system asks for reduced motion — every point is simply on the slide from the start, in all five styles. Toggle it above and step through.
